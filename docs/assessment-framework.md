# Assessment Framework

The AI Governance Readiness Assessment evaluates organizational maturity across **nine governance dimensions**.

## Categories and Weights

| # | Category | Weight | Focus Areas |
|---|----------|--------|-------------|
| A | Accountability & Governance | 15% | Ownership, policies, roles, escalation, oversight, inventory |
| B | Human Oversight | 15% | Human involvement, override, training, automation bias, challenges |
| C | Privacy & Data Governance | 15% | Data collection, retention, access, quality, privacy risks |
| D | Fairness & Non-Discrimination | 15% | Bias testing, demographics, protected groups, monitoring |
| E | Transparency & Explainability | 10% | AI disclosure, documentation, limitations, explanations |
| F | Security & Robustness | 10% | Cybersecurity, validation, monitoring, incident response |
| G | AI Impact & Risk Management | 10% | Impact assessment, harms, mitigation, approval process |
| H | Monitoring & Lifecycle Management | 5% | Post-deployment monitoring, drift, reviews, retirement |
| I | Accountability to Affected People | 5% | Complaints, challenges, remediation, adverse impacts |

**Total weight: 100%**

## Response Scale

Each question uses a defined maturity scale:

| Response | Value | Normalized Score |
|----------|-------|------------------|
| Fully implemented | 4 | 1.00 |
| Mostly implemented | 3 | 0.75 |
| Partially implemented | 2 | 0.50 |
| Planned | 1 | 0.25 |
| Not implemented | 0 | 0.00 |
| Not applicable | excluded | — |

## Governance Objectives

Each question maps to:

- **Category** — which dimension it belongs to
- **Risk level** — low, medium, high, or critical if unaddressed
- **Governance objective** — what control or practice is being assessed
- **Recommendation mapping** — which recommendation rule fires on low scores

Questions will be seeded in Phase 2 based on the specification in the project requirements.
